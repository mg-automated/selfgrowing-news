# Privacy

The Growing News Archive does not use advertising, behavioural analytics, user accounts, contact forms, or marketing trackers.

## Hosting

The site is hosted by GitHub Pages. GitHub states that it logs and stores visitors' IP addresses for security purposes, whether or not a visitor is signed in to GitHub. GitHub processes this information under its own [Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## Browser-local preferences

The site may store interface preferences in the visitor's browser, such as the selected colour theme, reader mode, or the open and closed state of navigation folders. These preferences support the requested interface and are not used by this archive for advertising or behavioural profiling. They can be removed by clearing the site's browser data.

## Fonts and static resources

The site loads fonts and supporting static resources from third-party content-delivery services, including Google Fonts. When a browser requests these resources, the provider may receive technical information such as the visitor's IP address, browser details, and request time under its own privacy terms.

## External links

Daily briefings link to news organisations, public authorities, companies, and other external sources. Following those links takes the visitor to third-party websites governed by their own privacy practices.

## Questions

Privacy questions or correction requests can be submitted through the repository's [GitHub Issues](https://github.com/mg-automated/selfgrowing-news/issues). Do not post private or sensitive personal information in a public issue.
